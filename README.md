# 1st year anniversary quest

Мобильный статический сайт-квест для годовщины.

## Локальный запуск

Откройте `index.html` в браузере или запустите простой сервер:

```bash
python3 -m http.server 8080
```

## GitHub Pages

Статические файлы запушены в ветки `main` и `gh-pages`.

Чтобы включить публикацию:

1. Repository → **Settings** → **Pages**.
2. **Build and deployment** → Source: **Deploy from a branch**.
3. Branch: **gh-pages** / folder: **/(root)**.
4. Save.

После включения сайт будет доступен по адресу:

https://andrewkotelnikov1992.github.io/1_st_year/
